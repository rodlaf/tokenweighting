\section{Experiments}\label{sec:experiments}

Our experiments are designed around the thesis of Section~\ref{sec:methods}:
that under LoRA, intrinsic credit-assignment signals collapse to uniform,
and that Adapter-Residual Credit Assignment (ARCA) is the only intrinsic
scheme we study that preserves per-token structure in this regime. We
therefore report two complementary comparisons: a \emph{diagnostic
comparison} that measures the distribution of token weights produced by
each scheme under LoRA vs.\ full-parameter training, and a \emph{performance
comparison} that measures downstream accuracy on GSM8K with Qwen2.5. We
then vary LoRA rank to characterize how the collapse-and-rescue behaviour
changes with adapter capacity.

\subsection{Setup}

\paragraph{Models.} We use \texttt{Qwen/Qwen2.5-1.5B-Instruct} as our
primary model. This is a general-instruct model (not a math-tuned variant),
chosen on the basis of preliminary experiments which showed that the
math-tuned variant is already at its post-training ceiling on GSM8K and
provides little headroom for RL to produce differentiable improvements. For
selected ablations we additionally use the math-tuned variant as a
robustness check.

\paragraph{Dataset and reward.} We train on the \texttt{gsm8k/main} split
with prompts formatted under an explicit final-answer convention, and report
evaluation on the held-out GSM8K test split. Rewards are binary exact-match
against the reference answer after normalization.

\paragraph{Adaptation strategies.} Each method is run in two regimes: (i)
LoRA adaptation with rank $r \in \{4, 8, 16, 32, 64\}$ on the attention and
MLP projections, and (ii) full-parameter training. Beyond adaptation
strategy, all methods share the same rollout count, prompt formatting,
optimizer family, learning-rate schedule, and decoding parameters within a
regime, isolating the weighting scheme as the only algorithmic difference.

\paragraph{Weighting schemes.} We compare six weighting schemes: uniform
(baseline), surprisal, entropy-reduction, policy-divergence, critic-based
(learned value head), and ARCA. The first four are intrinsic schemes
described in Section~\ref{sec:methods}. The critic-based scheme follows a
learned value head trained with MSE against trajectory return and provides
a strong within-family comparison to the token-level-actor-critic
literature. ARCA is our proposed method.

\paragraph{Baselines.} Every weighting scheme is combined with both RLOO
and GRPO prompt-level advantages, giving a $6 \times 2$ grid of
configurations per adaptation regime.

\subsection{Diagnostic: Weight Concentration Across Schemes}

We measure how much per-token structure each scheme produces by logging,
during training, the Gini coefficient $G(w)$ and the effective-token
ratio $\mathrm{EffN}(w)/T$ of the token weights. Both metrics have a
direct interpretation: under uniform weighting, $G = 0$ and
$\mathrm{EffN}/T = 1$; under maximally concentrated weighting (one token
receives all credit), $G \to 1$ and $\mathrm{EffN}/T \to 1/T$.

\begin{figure}[t]
\centering
\fbox{\rule{0pt}{4.5cm}\rule{0.9\linewidth}{0pt}}
\caption{\textbf{LoRA rank ablation.} Left: weight concentration
($\mathrm{EffN}/T$) as a function of LoRA rank for surprisal,

capacity modulates both the collapse and the rescue effect. Plot to be

\label{fig:rank-ablation}
\end{figure}

Varying LoRA rank $r \in \{4, 8, 16, 32, 64\}$ allows us to test the
quantitative prediction of Section~\ref{sec:collapse}: as $r$ decreases,
the per-token log-probability differential becomes increasingly uniform
across positions, so intrinsic output-distribution schemes collapse
\emph{more strongly} to uniform. ARCA, whose position-discriminative power
is inherited from the base model's own activation pattern rather than from
the adapter's logit impact, is predicted by
Proposition~\ref{prop:arca-nondeg} to be comparatively robust.
Figure~\ref{fig:rank-ablation} reports the corresponding sweep.

\subsection{Methods Compared at a Glance}

The implemented training variants, shipped as YAML configs under
\texttt{experiment/hf/configs/experiments/}, are:
\begin{itemize}
    \item \textbf{Baselines (for every adaptation regime):} RLOO +
    uniform, GRPO + uniform, RLOO + surprisal, GRPO + surprisal, RLOO +
    entropy-reduction, GRPO + entropy-reduction, RLOO + divergence,
    GRPO + divergence, RLOO + critic.
    \item \textbf{Proposed (ARCA):} RLOO + ARCA, GRPO + ARCA.
    \item \textbf{LoRA rank ablation:} RLOO + ARCA at $r \in \{4, 64\}$
    paired with RLOO + uniform at the same ranks.
\end{itemize}
All configs share rollout count, prompt formatting, optimizer, learning
rate, KL regularization coefficient, and decoding hyperparameters within a
regime. This isolates the effect of token-level credit redistribution
from unrelated implementation choices.

\subsection{Training Procedure and Metrics}

The main experiment entrypoint is \texttt{experiment/hf/run\_experiment.py}.
For each minibatch of prompts, the script samples $K$ completions from the
current policy, computes binary rewards after full generation, constructs
either RLOO or GRPO prompt-level advantages, and applies the weighted
token-level objective from Section~\ref{sec:methods}. For modes that need
them, the script additionally computes reference-model log-probabilities
(via \texttt{model.disable\_adapter()} under LoRA) and, for ARCA, the
per-token adapter-residual norm from the last-layer hidden states.

The code records the following metrics at every logging interval: (i)
greedy accuracy on the evaluation split, (ii) pass@$k$, (iii) reward mean
and variance, (iv) completion length, (v) the Gini and effective-token
metrics described above, and (vi) for ARCA, the mean and maximum
per-token adapter-residual norm. These six metrics jointly allow us to
check whether a weighting scheme produced a meaningful signal
(metric group v), whether it actually trained (groups iii, iv), and
whether it improved downstream behaviour (groups i, ii).

\subsection{Compute}

The implementation is intentionally compact: intrinsic token weights are
computed from quantities already produced by the policy during rollout or
the subsequent teacher-forced forward pass. ARCA adds at most one
adapter-disabled forward pass per minibatch, which is identical to the
forward pass already needed for KL regularization against the reference
policy; this overhead is negligible relative to sampling costs. All runs
fit on a single H100-class accelerator. No learned reward model or search
tree is required.
